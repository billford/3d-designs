# 3D Designs

3D-printable models by BillfordX: fidgets, switch plates, planters and yard
signs. Every piece here was designed, printed, photographed and used by a
human; the CAD code and the documentation were written with AI.

Each folder has the STLs, the full OpenSCAD source, photos of the real print,
and a README that covers printing, assembly, remixing and **why it's built
the way it is**.
